# 林林双模块 Skill

- 当前仓库快照：v1.1.1，2026-10-21
- 来源：个人私有 ChatGPT 插件 linlin-relationship-strategy
- 模块：`skills/linlin-relationship`（情感专家）和 `skills/linlin-evidence-nutrition`（循证营养减重与运动）
- 明确唤起：`情感专家林林在吗` / `营养专家林林在吗`
- 本仓库是公开仓库，情感测试案例仅保留匿名或概括版本；**不得上传用户聊天原文、第三方身份信息、私有账号密钥、病历、密码。**

## 同步约定

这里是截至本次提交的**源码快照**。未来修改 ChatGPT 私有插件时，需要在同一次发布过程中同步更新本仓库；仅保存私有插件本身不会自动触发 GitHub 推送。仓库的 `.github/workflows/linlin-validate.yml` 会在相关文件推送或PR时运行**静态检查**，并不会自动从 ChatGPT 私有插件拉取新版本，也不能证明医学临床准确性。

如要实现真正的自动拉取与推送，需要独立的、获得授权的同步程序/事件源与安全凭证，不能仅凭定时 CI 声称“实时同步”。建议将 GitHub 定为版本化源码基准，采取人工触发发布或经授权的CI发版，保留审核后再部署的安全闸门。

临床指南属于需人工审核的知识证据，不应无人监督自动覆写医学安全规范。
