# 情感关系证据与投入决策手册

## 核心区分（非数学分数）

### 证据强度
- **不支持私人好感**：工作场景的职业微笑、因维护客源主动联络、顾客付费期间的情绪陪伴、对用户消息的礼貌回复。
- **有限支持私人舒适与友善**：无报酬的顺路帮助、被邀请后私人见面、友好回应、同意适当的请客预算、问候回家安全。单次只是善意，不代表浪漫。
- **更有力的双向私人投入**：主动开聊而不涉及交易、分享日常、对用户的生活提出主动关心、主动提出并落实私人邀约、双方自然互惠且在不同场景持续出现。
- **可能指向浪漫兴趣**：对方在双方自愿且清晰的前提下，主动表达想建立暧昧或亲密关系并用行为落实；仍要尊重语言与行为不一致时的边界。

### 替代解释的最小集
- 外出疲惫 ≠ 不尊重；特别是用户此前约过深夜付费陪伴。
- 她主动叫去店 ≠ 私人主动关注。
- 主动让回家报平安 ≠ 恋爱信号。
- 用户要求说晚安后她说晚安 ≠ 主动发起。
- 同意共同旅行/假设婚姻 ≠ 已规划共同未来。
- 同意请一次小额餐饮但没约时间 ≠ 已经兑现。
- 同事转述/吃醋 ≠ 私人兴趣；可能是客源竞争或不喜欢尴尬。

## 投入结构（不要做物化评分）

用实际体验来评估：
1. **现金支出**：当期花费、月预算、是否因为某个人而超过正常娱乐预算。适用时可计算例如 `每小时总花费 = 账单 / 实际陪伴时长`，但不可把这个当成人的价值。
2. **时间与机会成本**：等待、休息、熬夜、交通、错过其他活动。
3. **情绪净收益**：相处时是否开心、事后是否持续纠结影响睡眠或工作。
4. **平等与自愿**：是否尊重拒绝、界限，是否双方可自由说“不”。
5. **路径依赖**：花过的钱不能成为继续付钱的理由；对方曾给过温暖不意味着必须持续投入。

### 决策阈值（方向，不是机械评分）
- **继续**：相处让用户高兴，投入在承受范围内，边界清楚且存在自然互惠。
- **降投入**：主要主动方是用户、付费场景证据多于私人证据、持续失望或费用超预算。
- **暂停**：出现情绪失控、大额损失、胁迫、赌博债务牵连、持续不尊重界限。私人关系可保留正常礼貌，但避免继续资金投入。
- **退出**：持续的欺骗、威胁、剥削、反复违背明确边界或用户不再享受相处。

## 审核式决策

输出应写清楚：
- `事实`（至少一条具体行为）
- `推断`（含不确定性）
- `当前动作`（明确）
- `未来扳机`（什么新行为会改变判断）

不能让“她主动联系你了”掩盖联系只是为成交付费的事实。不能把“你会被她惦记”当作可通过话术保证的结果。
