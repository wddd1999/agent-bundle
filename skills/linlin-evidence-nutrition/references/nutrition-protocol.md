# 营养与减重执行协议（成人一般健康教育）

## 0 评估和分类

需要有本人授权的身高、体重、年龄范围、腰围、体重趋势、训练史、疾病药物、饮食习惯和目标。BMI = kg / m²；中国成年人 `<18.5`低体重，`18.5–<24`正常，`24–<28`超重，`≥28`肥胖（据CN-OB24），不适用于儿童与孕期体重评价。腰围男≥90cm、女≥85cm提示中心型肥胖；如性别相关测量信息不明，不自动推断性别。注意 BMI 高可源于肌肉量高，BMI正常可存在中心脂肪；两者都不能诊断全部健康状态。

## 1 优先规划食物结构

- 以健康饮食的可持续改变为先：适量主食与全谷、足够非淀粉类蔬菜、水果、豆类、奶/替代品、鱼禽蛋瘦肉/合理植物蛋白、适量不饱和脂肪；减少含糖饮料、酒精、超加工高能量食物；保留饮食文化、可负担性、口味和应酬场景。
- 参考中国居民膳食指南（一般成人）：新鲜蔬菜≥300g/日、鲜果200–350g/日（果汁不代替），其他份量随年龄/需求及疾病调整；不把“多吃蔬菜”误读为可忽略所有营养素。
- 粤菜/外食优先可执行替换：白灼、清蒸、少油炒、搭配蔬菜；注意隐藏的炒菜油、酱料、奶茶、甜汤及酒；不妖魔化米饭、粥或单一食物。
- 蛋白质以满足需求为主，瘦体重维护可结合抗阻训练；健康抗阻训练成人的蛋白研究可以作为沟通参考，但不是要求每人一律 1.6g/kg/日。老年、肾病、特定疾病、严重肥胖个体使用实际/目标/调整体重作为基数有争议，必须个体化并可转营养师。
- 不规定所有人必须生酮、断食、无碳水、不吃晚饭、用某种保健品。没有安全证据的“排毒”“排宿便”“燃脂药茶”不推荐。

## 2 能量估算，不伪精确

**仅供成人、无特殊医疗禁忌、输入足够时**，可从静息代谢估计量结合活动水平得到日能量消耗范围；模型依赖体重、身高、年龄、性别生理参数、活动估计，缺一无法可靠精算。可按需要使用 Mifflin-St Jeor 方程（1990原始研究，见证据库 MSJ-1990；对成人人群的估算，并非代谢实测）：
- 传统男性常数：`10×体重kg + 6.25×身高cm − 5×年龄 + 5`
- 传统女性常数：`10×体重kg + 6.25×身高cm − 5×年龄 − 161`
- 如果不知适用参数，给区间或不用公式；对跨性别用户、有特殊体成分者谨慎说明方程不确定性，不作性别身份假定。
- 活动系数常见 1.2–1.7+ 只是粗糙初始估计，不代表实测TDEE；疾病、非运动活动与代谢适应、设备偏差可显著影响。
- 适合减重的成人先从可维持且营养完整的小到中等能量缺口讨论。**ADA 2026 500–750 kcal/日为特定糖尿病合并超重/肥胖群体的结构化干预框架，不能默认所有人都要减去这么多**。定期依据体重趋势和饥饿/运动表现调整。
- 预测体重必须注明区间与不确定性；不直接用“每天少500 × 90天 ÷7700 = 精确瘦x公斤”承诺结果。

## 3 分步行动模板

1. 确认健康安全与现实目标，不能一次性“90天必瘦xx公斤”。
2. 初期用实际餐食或 3–7 日代表性饮食记录识别高影响变化（如饮料/宵夜/烹调油/大份量），对进食障碍风险者禁止强制食物日志。
3. 选择两至三个具体替换，优先固定蛋白食物、蔬菜和饮水，在用户饮食风格内节能量而不漏营养。
4. 饥饿或疲劳剧烈、便秘、训练能力明显下降、头晕等及时复核，不强行继续。
5. 设每周回顾、4周一次策略复盘；长期维持比短期秤面数字更重要。

## 4 特殊饮食、临床情况

- 糖尿病服用降糖药特别是胰岛素/磺脲类者，运动、限碳和禁食可能诱发低血糖；绝不建议擅自减少药量或长期跳餐。
- 慢性肾病、肝硬化、孕哺、未成年人、脆弱老年人、糖尿病伴胃轻瘫等需要专业营养方案，避免套用蛋白和热量公式。
- 有进食障碍风险/低体重或疑似营养不良，不提供节食计划。
- NICE 的 800–1200kcal/日低能量及<800kcal/日极低能量饮食有专科条件、营养完整性、疗程与随访要求，普通生活方式聊天不得推荐为日常自助计划。
- 对疑似营养素缺乏，不凭症状给高剂量补剂，建议专业评估/必要检查；补充剂需评估与处方药相互作用。
