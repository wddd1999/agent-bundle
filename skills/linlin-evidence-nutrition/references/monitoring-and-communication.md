# 进展监测与沟通

## 基线→复盘

- 用用户愿意且健康安全的方式跟踪：晨起同条件体重（可每周一至数次，以7–14日/每周均值观察）、腰围（每2–4周）、衣服合身程度、运动能力、睡眠、饥饿与心情。对进食障碍高风险群体避免让每日称重或卡路里记录成为任务。
- 对一般适合减重的成人，可将“初始体重5%–10%左右的长期改善”作为可讨论的阶段目标而非治疗保证；目标由用户需求、病史、指标调整，不能从一次测量定死终点。
- 1天体重浮动受水、食物残留、糖原、盐分、月经及测量条件影响，不解读为瞬间增减同等脂肪。
- 平台期判断应先确认大约连续3–4周在可比条件下**趋势**未变化，再核对记录、饥饿感、依从性、活动变化、药物和睡眠；不是见一两次反弹就减更多热量。
- 出现持续疲惫/头晕、强迫行为、睡眠恶化、疼痛或异常化验时先暂停加码和寻求医疗评估。

## 反馈决策

1. 有趋势改善且精力、健康尚可 → 保持原计划；不为追求更快而加大赤字。
2. 体重不变但腰围/训练性能在改善 → 考虑体成分变化与测量噪音；检查健康和可持续性。
3. 长期趋势偏离预期 → 先核对基线TDEE假设和实际生活环境，再小幅、逐项调整；不一口气低热量＋大运动量。
4. 目标已达到 → 从减重过渡到维持，恢复可持续能量平衡和饮食弹性，不长期强制缺口。

## 回答风格与透明性

- 一句话回答用户眼下要解决的问题，再简要解释理由；需要计划才按周展开。
- 精确给“有依据的范围”和用户可操作的条件，避免冒充体脂实测、热量精确计算或保证xx天瘦xx斤。
- 文末标注最关键的1–3个可核验来源（机构、年份、网页），优先原始指南；未检索时仅可注明静态参考的时间点，不要冒称实时核实。
- 感情与饮食交叉：不对“被爱需要瘦身”做价值判断，不把恋爱挫折直接归因于体型；情绪压力下支持适当睡眠/运动/进食，但不医学化或操控。
